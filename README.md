# Проект «Место»

Интерактивная страница для добавления фотографий мест, редактирования профиля, лайков и удаления своих карточек. Данные загружаются и сохраняются через API.

## Ссылка на проект

[GitHub Pages](https://YOUR-GITHUB-USERNAME.github.io/mesto-ad/)

> Замените `YOUR-GITHUB-USERNAME` на ваш логин GitHub после публикации проекта.

## Функциональность

- загрузка карточек и данных профиля с сервера;
- редактирование имени и описания профиля;
- добавление и удаление своих карточек (с подтверждением);
- лайки с отображением количества;
- валидация всех форм;
- **дополнительное задание:** обновление аватара пользователя через API.

## Технологии

HTML, CSS (БЭМ), JavaScript (ES6 modules), Fetch API.

## Запуск локально

1. Клонируйте репозиторий.
2. Укажите свой `cohort` и `authorization` в файле `src/scripts/utils/config.js`.
3. Запустите проект через расширение Live Server в VS Code.

## Структура

- `src/scripts/components/api.js` — класс для работы с API;
- `src/scripts/components/validation.js` — класс валидации форм;
- `src/scripts/components/card.js` — создание карточек;
- `src/scripts/index.js` — точка входа приложения.
